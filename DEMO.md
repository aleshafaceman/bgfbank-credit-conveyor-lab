## Перед показом

1. Клиент: **Настройки → Демо-режим → Сбросить демо-данные**.
2. Обновить вкладку менеджера (**Ctrl+F5**).
3. Один браузер, две вкладки (общий `localStorage`). Телефон + ноутбук **не** синхронизируются.

Проверка перед релизом: `node scripts/pre-release-audit.js` (должно быть Failed: 0).

## Happy-path (5–7 мин)

1. Клиент: вход → **Мои заявки** → активная №4421-И (или **Новая заявка**).
2. Конвейер: объект залога → **ЕСИА** → прескоринг → пакет «Рекомендуем» → принять.
3. Чат: клиент пишет → на вкладке менеджера сообщение появляется без F5 (и наоборот).
4. Менеджер: заявка → **Полный скоринг** (в демо всегда зелёный) → одобрение.
5. Клиент: статус «Одобрено». Для повтора — **Новая заявка** или сброс демо.

## Не кликать на сцене

- «Ипотека» (заглушка).
- Регистрацию нового пользователя (ломает персону Кузнецова).
- Standalone `scoring_negative.html` (намеренно негативный сценарий).
- Повторный «Запустить прескоринг» после принятого пакета без нужды — ставка сохранится, но сценарий удлинится.

## Если что-то «залипло»

- **Новая заявка** на клиенте.
- Или **Сбросить демо-данные** + F5 на обеих вкладках.
