## Перед показом

1. На экране входа клиента или в сайдбаре / шапке менеджера: **«Сбросить демо · готово к показу»**.
2. **Ctrl+F5** на обеих вкладках.
3. Один браузер, две вкладки (общий `localStorage`).

Проверка: `node scripts/pre-release-audit.js` (Failed: 0).

## Happy-path (5–7 мин)

1. Клиент: вход → **Мои заявки** → №4421-И → **Продолжить оформление**.
2. Объект залога (карточка Ocenka/LTV) → **ЕСИА** → прескоринг → пакет «Рекомендуем» (разбор ставки) → принять.
3. После принятия: «Ожидает решения менеджера» → быстрый ответ в чате («Когда решение?»).
4. Менеджер: вкладка Чат (пульс/тост) → заявка → **Полный скоринг** (быстрый режим ~3 сек, зелёный) → одобрение.
5. Клиент: тост «Менеджер одобрил…» + статус «Одобрено».

Клавиша **P** — режим проектора.

## Не кликать на сцене

- Регистрацию нового пользователя.
- Standalone `scoring_negative.html`.
- Повторный прескоринг после принятого пакета без нужды.

## Если залипло

- **Сбросить демо** на входе / в шапке.
- Или **Новая заявка** на клиенте.
