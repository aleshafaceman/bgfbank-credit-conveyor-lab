1. Как читать схему

ЛК — это фронт cabinet / admin-cabinet и бэкенд partner-api. Внешняя интеграция — система за границей этого репозитория (вендор, банк, государство) либо отдельный шлюз, которого нет в данном дистрибутиве.

Ядро ЛК Прямой вызов из ЛК Шлюз / канал лидов За ELMA — ЛК не вызывает

Есть в этом дистрибутиве

  • ELMA3, DaData, Мобильный оценщик
  • SMS MFMS, почта банка, Basis OCR
  • CIAN, AmoCRM, Calltouch, Скорозвон, Банки.ру, VK, Метрика

Нет в коде этого дистрибутива

  • TrustGate — ссылка на Госуслуги с первого экрана, согласие и сведения ЕСИА
  • Шлюз Open Banking — лиды внешних лидогенераторов, ETL, оффер и статус
Solver (калькулятор LTV и пакетов) — внутренний сервис платформы, не СПР банка. Скоринг, БКИ и решение АНД считает Loginom внутри ELMA.

2. Контекст: граница ЛК и внешний мир

Кабинет ходит во внешний мир напрямую только в ограниченный набор систем. Loginom, ЦФТ и Smartdeal из ЛК не вызываются.

3. Прямые интеграции ядра ЛК

То, что partner-api вызывает сам, без посредника-шлюза.

Мобильный оценщик — три канала

Канал Хост Назначение Задача в админке МО
Lookup api.ocenka.mobi Справочник по адресу и кадастру Нет
Express express.ocenka.mobi Полноценная express-оценка Да
Через ELMA RequestExpressEvaluation Официальная AppraisalPledgeCost Зависит от флага SendToMobileAppraiser

DaData — подсказки адреса, это не оценка. Партнёр на адресе может записать building_price из lookup; менеджер идёт в express / ELMA.

4. ELMA — шина кредитного конвейера

ELMA3 — главная внешняя система кабинета: каталог пользователей, прескоринг, АНД, статусы, оценка, КВ. Без записи в ELMA (elma_id) в кабинет не пускают.

Входящие webhook ELMA → ЛК

Эндпоинты /api/elma/...: смена статуса лида и полной заявки, официальная цена залога, чеклист доработки, дубли, архив, конвертация UID. Через эти колбэки ЛК узнаёт исходы Loginom (PRIOR_APPROVE / PRIOR_FAIL / отказ), не вызывая Loginom сам.

5. TrustGate: Госуслуги / ЕСИА

Контура нет в данном дистрибутиве. В проде ЛК с первого экрана отдаёт клиенту ссылку TrustGate; шлюз проводит авторизацию на Госуслугах и возвращает согласие и сведения ЕСИА.

Не путать с SMS-согласием сервиса consent (ПДн + БКИ банка) и с OTP входа в кабинет (MFMS). TrustGate закрывает идентичность через Госуслуги и цели ЦПГ.

Что Детали
Точка входаПервый экран ЛК: отправка ссылки клиенту
Что делает клиентАвторизация на Госуслугах по ссылке TrustGate

Что TrustGate не отдаётОбъект залога. Квартиру клиент вводит в ЛК (адрес / кадастр), не из ЕСИА

6. Шлюз Open Banking: лидогенераторы

Отдельный интеграционный шлюз, его нет в этом репозитории. Это не reception и не extpartner. Лидогенераторы не пишут в ЛК свой JSON: шлюз нормализует данные, создаёт заявку, забирает оффер и отдаёт статус.
Шаг Кто Что происходит
1. Приёмшлюз ← лидогенераторПроизвольный JSON вендора
2. ETLшлюзПриведение к контракту ЛК
3. Созданиешлюз → ЛКЗаявка в кабинете
4. ОфферЛК → solver → шлюз → лидогенПрескоринговые пакеты, не скоринг Loginom
5. Статуслидоген → шлюз → ЛКОпрос статуса заявки

Ответственность шлюза

  • Контракт Open API для вендоров
  • ETL и изоляция чужих форматов
  • Выдача оффера и статуса наружу

Ответственность ЛК

  • Карточка заявки и калькулятор
  • Проекция статусов
  • Дальше — ELMA, не Loginom/ЦФТ из шлюза

Оффер на этом контуре — витрина Solver (LTV, ставка, пакеты). Решение банка после АНД приходит статусом из ELMA; шлюз может отдать лидогенератору уже эту проекцию.

8. Что стоит за ELMA

Банковский конвейер. Из кабинета видны статусы и отдельные поля (например IDClientCFT). Прямых клиентов в коде ЛК нет.

Система Роль Как видно из ЛК
LoginomПрескоринг preScore, скоринг getDecision, ФССП, ПДНИсходы статусов, без прямого клиента
ЦФТКлиент, кредитный договор, аккредитив, закладнаяПоле IDClientCFT, флаг отправки отказа
SmartdealЭлектронное подписание КОД и регистрацияВ репозитории ЛК следов нет
БКИКредитная историяЧерез Loginom после согласия

Граница двух шлюзов. TrustGate закрывает идентичность и согласие ЦПГ на входе анкеты. Шлюз Open Banking закрывает оптовый канал лидогенераторов с чужим JSON. Оба стоят снаружи кабинета и не смешиваются с consent, extpartner и reception из этого репозитория.
