## 1. Назначение

**Findsign** - сервис для поиска и валидации подписей в распознанных документах. Использует компьютерное зрение и OCR для определения наличия подписи и ее координат на документе.

### Технологии

- FastAPI
- OpenCV (cv2) - обработка изображений
- Tesseract OCR (pytesseract) - распознавание текста
- PIL (Pillow) - работа с изображениями
- pdf2image - конвертация PDF в изображения
- Levenshtein - сравнение строк для поиска текста "подпись"
- JWT аутентификация

## 2. Модели данных

### Схемы данных

#### FindsignRequestData

**FindsignRequestData** - входная схема для поиска подписи.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | int | ID заявки/согласия (обязательно) |
| `file` | str | Файл в base64 (обязательно) |
| `needs_result_file` | bool | Нужен ли файл с результатом (по умолчанию False) |

#### PreparedFileInfo

**PreparedFileInfo** - выходная схема с информацией о файле.

| Поле | Тип | Описание |
|------|-----|----------|
| `md5` | str | MD5 хеш файла |
| `content_type` | str | MIME тип файла |

### Классы обработки

#### Document

**Document** - класс для представления документа с изображениями.

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | str | Название документа |
| `pages` | List[Page] | Список страниц документа |
| `md5` | hashlib._hashlib.HASH | MD5 хеш файла |

**Методы:**

- `find_suitable_contours()` - поиск подходящих контуров на всех страницах
  - Возвращает список `[page, contours_list]` для каждой страницы

#### Page

**Page** - класс для представления одной страницы документа.

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `_image` | PIL.Image.Image | Исходное изображение |
| `image` | np.array | Изображение в формате OpenCV |
| `page_num` | int | Номер страницы |

**Методы:**

- `find_suitable_contours()` - поиск подходящих контуров на странице
  - Возвращает список `[[kernel_size, contours], ...]`

#### Reader

**Reader** - класс для чтения и предварительной обработки файлов.

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `file_path` | Path/str | Путь к файлу |
| `images` | List[PIL.Image.Image] | Список изображений |
| `file_md5` | hashlib._hashlib.HASH | MD5 хеш файла |
| `file_type` | str | MIME тип файла |

**Методы:**

- `read(file_path)` - чтение файла и извлечение изображений
  - Поддержка PDF (конвертация в изображения)
  - Поддержка изображений (JPEG, PNG и т.д.)
  - Вычисление MD5 хеша
  - Определение типа файла через `magic`

- `get_file_type(file_path)` (staticmethod) - определение типа файла
  - Использует `magic.from_file()` для определения MIME типа

#### Recognizer

**Recognizer** - класс для распознавания и поиска подписи.

**Параметры класса:**

- `default_lang: str = "rus"` - язык OCR
- `default_oem_psm_config: str = "--oem 3 --psm 6"` - конфигурация Tesseract
- `templates_folder` - папка с шаблонами
- `default_by: List[str] = ["подпись"]` - ключевые слова для поиска

**Методы:**

- `recognize_image(image, psm_config, lang)` (classmethod) - распознавание изображения
  - Использует `pytesseract.image_to_data()`
  - Возвращает список словарей с данными распознавания
  - Каждый элемент содержит: `text`, `left`, `top`, `width`, `height`, `conf`

- `find_sign_row(lexems, by)` (classmethod) - поиск строки с текстом "подпись"
  - Использует расстояние Левенштейна для сравнения
  - Порог расстояния: `< 5`
  - Возвращает отсортированный список `[[distance, item], ...]`

- `find_sign(recognizing_doc)` (classmethod) - основной метод поиска подписи
  - Алгоритм:
    1. Поиск подходящих контуров на всех страницах
    2. Для каждой страницы:
       - Подготовка изображения (увеличение яркости)
       - OCR распознавание
       - Поиск текста "подпись" или "Подпись"
       - Если найдено (расстояние <= 3):
         - Вычисление центра блока с текстом
         - Поиск ближайшего контура к центру
         - Проверка расстояния (< 1000 пикселей)
         - Если найден → возврат результата
  - Возвращает: `[page_num, lev_dist, min_dist, sign_block, contour]` или `None`

#### Processor

**Processor** - класс для обработки изображений.

**Методы:**

- `find_contours(hsv_image, color_name, kernel_size)` (classmethod) - поиск контуров
  - Фильтрация по цвету в HSV пространстве
  - Морфологические операции (dilate, closing)
  - Детекция краев (Canny)
  - Возвращает контуры и иерархию

- `prepare(image, factor, blur, brightness, contrast)` (classmethod) - подготовка изображения
  - Изменение размера (если `factor > 0`)
  - Размытие (если `blur > 0`)
  - Увеличение яркости (если `brightness > 0`)
  - Увеличение контраста (если `contrast > 0`)

- `increase_brightness(image, value)` (classmethod) - увеличение яркости
  - Работа в HSV пространстве
  - Увеличение канала V

- `increase_contrast(image, value)` (classmethod) - увеличение контраста
  - Использует CLAHE (Contrast Limited Adaptive Histogram Equalization)
  - Работа в LAB пространстве

- `get_block_center(item, factor)` (classmethod) - вычисление центра блока
  - Из координат `left`, `top`, `width`, `height`
  - Возвращает `[center_x, center_y]`

- `draw_lexem_boxes(image, lexems_list, factor)` (classmethod) - отрисовка рамок
  - Рисует прямоугольники вокруг распознанных текстовых блоков
  - Для отладки и визуализации

#### Finder

**Finder** - класс для поиска подходящих контуров.

**Параметры:**

- `DEFAULT_KERNEL_SIZE = 2` - размер ядра по умолчанию
- `MAX_ITERATIONS = 4` - максимальное количество итераций
- `MIN_LENGTH_PX = 500` - минимальная длина периметра контура

**Методы:**

- `find_suitable_contours(image, color_name, kernel_size, iterations, min_length)` (classmethod)
  - Поиск контуров синего цвета (по умолчанию)
  - Итерации с разными размерами ядра
  - Фильтрация по периметру (>= min_length)
  - Фильтрация по высоте (30 < h < 300)
  - Возвращает список `[[kernel_size, relevant_contours], ...]`

## 3. Бизнес-логика

### Обработка запроса на поиск подписи (`POST /api/findsign`)

**Процесс:**

1. **Декодирование файла:**
   - Декодирование base64 в бинарные данные
   - Создание временного файла

2. **Чтение файла:**
   - Создание `Reader`
   - Вызов `reader.read(file_path)`
   - Извлечение изображений (PDF или изображения)
   - Вычисление MD5 хеша

3. **Создание документа:**
   - Создание `Document` из списка изображений
   - Установка MD5 и названия

4. **Фоновая задача:**
   - Добавление задачи `check_sign` в `BackgroundTasks`
   - Параметры: `id`, `recognizing_doc`, `needs_result_file`

5. **Возврат результата:**
   - `md5` - хеш файла (hexdigest)
   - `content_type` - MIME тип файла

**Ошибки:**

- Если нет изображений → `InvalidRequestException` (403)

### Проверка подписи (`check_sign`)

**Процесс:**

1. **Поиск подписи:**
   - Вызов `Recognizer.find_sign(recognizing_doc)`
   - Получение результата: `[page_num, lev_dist, min_dist, sign_block, contour]`

2. **Определение результата:**
   - Если `sign_data` не пустой → `has_sign = True`
   - Иначе → `has_sign = False`

3. **Отправка результата в partner API:**
   - Создание `AuthRealmRequestWrapper` с настройками B2B
   - POST запрос на `update_consent_sign`
   - Данные: `{"id": instance_id, "has_sign": has_sign}`

4. **Возврат результата:**
   - Возврат `has_sign` (bool)

### Алгоритм поиска подписи

**Шаги:**

1. **Поиск контуров:**
   - Для каждой страницы документа
   - Поиск контуров синего цвета (подпись обычно синяя)
   - Фильтрация по размеру (высота 30-300 пикселей)
   - Фильтрация по периметру (>= 500 пикселей)

2. **OCR распознавание:**
   - Подготовка изображения (увеличение яркости на 30)
   - Распознавание через Tesseract OCR
   - Извлечение текстовых блоков с координатами

3. **Поиск текста "подпись":**
   - Поиск в распознанном тексте слова "подпись" или "Подпись"
   - Использование расстояния Левенштейна (порог <= 3)
   - Получение координат блока с текстом

4. **Сопоставление с контуром:**
   - Вычисление центра блока с текстом "подпись"
   - Поиск ближайшего контура к центру
   - Проверка расстояния (< 1000 пикселей)
   - Если найден → подпись обнаружена

5. **Результат:**
   - Если подпись найдена → возврат данных о подписи
   - Иначе → возврат `None`

### Обработка изображений

**Подготовка изображения:**

1. **Изменение размера** (опционально):
   - Пропорциональное изменение через `resize_proportional()`
   - Интерполяция: `cv2.INTER_CUBIC`

2. **Размытие** (опционально):
   - Гауссово размытие через `cv2.GaussianBlur()`

3. **Увеличение яркости** (опционально):
   - Работа в HSV пространстве
   - Увеличение канала V (яркость)

4. **Увеличение контраста** (опционально):
   - CLAHE для адаптивной эквализации гистограммы
   - Работа в LAB пространстве

**Поиск контуров:**

1. **Преобразование в HSV:**
   - `cv2.cvtColor(image, cv2.COLOR_BGR2HSV)`

2. **Фильтрация по цвету:**
   - Создание маски через `cv2.inRange()`
   - Диапазон HSV для синего цвета

3. **Морфологические операции:**
   - Дилатация (`cv2.dilate`)
   - Закрытие (`cv2.morphologyEx` с `MORPH_GRADIENT`)

4. **Детекция краев:**
   - Алгоритм Canny (`cv2.Canny`)
   - Пороги: 175, 175

5. **Поиск контуров:**
   - `cv2.findContours()` с `RETR_TREE` и `CHAIN_APPROX_SIMPLE`

## 4. API Endpoints

### `POST /api/findsign`

**Назначение:** Поиск подписи в распознаваемом файле документа.

**Аутентификация:** JWT токен (x-token header)

**Запрос:**
```json
{
  "id": 123,
  "file": "base64_encoded_file_content",
  "needs_result_file": false
}
```

**Ответ:**
```json
{
  "md5": "a1b2c3d4e5f6...",
  "content_type": "image/jpeg"
}
```

**Процесс:**
- Декодирование base64 файла
- Чтение и обработка файла
- Создание фоновой задачи для поиска подписи
- Возврат информации о файле

**Ошибки:**
- `InvalidRequestException` (403) - ошибка обработки файла

## 5. Интеграции

### Partner API

**Отправка результата:**

- **Endpoint:** `update_consent_sign`
- **Метод:** POST
- **Данные:**
  ```json
  {
    "id": 123,
    "has_sign": true
  }
  ```
- **Аутентификация:** Через `AuthRealmRequestWrapper` с B2B настройками

**Использование:**

- Проверка наличия подписи в загруженных документах согласия
- Обновление статуса согласия в partner API

### Recognition API

**Интеграция:**

- Findsign работает с результатами распознавания документов
- Может использоваться после OCR для дополнительной проверки подписи

## 6. Особенности архитектуры

### Обработка файлов

**Поддерживаемые форматы:**

- **PDF:** Конвертация в изображения через `pdf2image`
- **Изображения:** JPEG, PNG и другие форматы через PIL

**Определение типа:**

- Используется библиотека `magic` для определения MIME типа
- Автоматическая обработка в зависимости от типа

### Компьютерное зрение

**Поиск контуров:**

- Фильтрация по цвету в HSV пространстве
- Морфологические операции для улучшения качества
- Детекция краев через алгоритм Canny

**Параметры поиска:**

- Минимальная высота контура: 30 пикселей
- Максимальная высота контура: 300 пикселей
- Минимальный периметр: 500 пикселей
- Максимальное расстояние от текста до контура: 1000 пикселей

### OCR распознавание

**Настройки Tesseract:**

- Язык: русский (`rus`)
- OEM: 3 (LSTM OCR Engine)
- PSM: 6 (Единый блок текста)

**Поиск текста:**

- Использование расстояния Левенштейна для сравнения
- Порог расстояния для слова "подпись": <= 3
- Порог расстояния для поиска: <= 5

### Асинхронная обработка

- Поиск подписи выполняется в фоновой задаче
- Не блокирует ответ API
- Результат отправляется в partner API асинхронно

### Безопасность

- JWT аутентификация через `verify_token_header`
- Валидация входных данных через Pydantic
- Обработка ошибок с логированием

### Производительность

- Обработка изображений через OpenCV (оптимизировано)
- Параллельная обработка нескольких страниц
- Кэширование результатов (опционально)

## 8. Примеры использования

### Пример запроса

```python
import base64
import requests

# Чтение файла
with open("document.pdf", "rb") as f:
    file_content = base64.b64encode(f.read()).decode()

# Запрос
response = requests.post(
    "https://findsign-api.example.com/api/findsign",
    headers={
        "x-token": "jwt_token_here",
        "Content-Type": "application/json"
    },
    json={
        "id": 123,
        "file": file_content,
        "needs_result_file": False
    }
)

# Результат
result = response.json()
print(f"MD5: {result['md5']}")
print(f"Content Type: {result['content_type']}")
```

### Пример результата поиска

**Если подпись найдена:**

- `page_num` - номер страницы (1, 2, ...)
- `lev_dist` - расстояние Левенштейна до слова "подпись" (0-3)
- `min_dist` - расстояние от текста до контура (пиксели)
- `sign_block` - данные блока с текстом (координаты, размер)
- `contour` - найденный контур подписи

**Если подпись не найдена:**

- Возвращается `None`
- `has_sign = False` отправляется в partner API
