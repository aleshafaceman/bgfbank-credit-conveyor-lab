Роли: инициатор, группа сотрудников процессинга КОД, процессор КОД, сотрудник продаж / процессор B2B, ЦФО. Ключевые интеграции — ЦФТ (в т.ч. ЦФТ РКО) и Loginom.Фаза 1. Инициация. Передача параметров в ЦФТ, синхронизация контекста, обновление блоков УС, определение срока исполнения КОД, распределение заявки, назначение процессора КОД и выдача прав, проверка арестов по счетам.Фаза 2. Подготовка данных участников и ДУ. Обновление клиентов в ЦФТ, формирование и обработка списка участников, создание/обновление клиента в ЦФТ, обновление электронной закладной, списки ДУ и уведомления, параметры коллективной страховки.Фаза 3. Формирование КОД (ключевой шаг). Подготовить информацию по КОД → сформировать КОД: запросы в ЦФТ и ЦФТ РКО (с обработкой ошибок Loginom, повтором, эскалацией в ИТ), аккредитив, комплект документов, проверка предельного ПСК, закладная по шаблону, проверка прав, формирование и генерация документов, создание КД (тестовая среда / STAGE), заявка на УКЭП.Фаза 4. Доработка (продажи / B2B / ЦФО). Доработка по заявке (распределение, комментарии, доработка на этапе подготовки сделки, возврат, отказ клиента); отправка в ОБУКО и исправление паспортных данных клиента в ЦФТ.Фаза 5. Завершение. Обновление события подготовки информации по КОД → передача статуса в B2B (сделка) → заключение сделкиПроблемы:Явных проблем на данный момент выделить не могу
