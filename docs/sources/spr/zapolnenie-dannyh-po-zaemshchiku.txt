Проверка на активные процессы, подготовка заявки и синхронизация контекста, распределение заявок (Продажи/КЦ), формирование ответственных и выдача прав, автоматические проверки: страховки, ФССП (через Loginom), уведомление по ДУ, проверка ЦП. Далее — передача процессору B2B.Заполнение данных заёмщика (процессор B2B). Ключевой шаг — заполнение данных по заёмщику; доступны ранний расчёт ПДН и выгрузка последней версии отчёта. После — обработка результатов оценки.Развилка по результату. Отправка на процессинг (CheckBL, расчёт приоритета) с переходом к процессингу заёмщика; отправка на оценку залога с экспресс-оценкой; возврат на сбор документов (доработка) с оповещением «Сбор документов АНД»; отказ клиента. Статусы передаются в B2B.Проблемы:Три исхода (на процессинг / на оценку залога / на доработку) не синхронизированы между собой — заёмщик может уже уйти в процессинг, пока по этой же заявке параллельно висит доработка, и непонятно, какой статус в моменте главный.
