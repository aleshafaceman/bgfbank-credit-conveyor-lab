Процессинг заемщикаКраткая сводкаОтветственный Чернов Георгий Григорьевич Статус описанияУТВЕРЖДЕН НА СОГЛАСОВАНИИ НЕ УТВЕРЖДЕНКраткое описаниеКонтекстЗадействованные системы: ElmaВнешние интеграции: экспресс-оценкаРоли: Ответственный по заявкеВизуальная схема/Пошаговое описаниеЭтап отвечает за приём результатов экспресс-оценки залога по заявке и обновление параметров залога.Инициация. Определение ответственного по заявке, проверка этапа заявки, шлюз обработки: часть заявок завершается сразу.Маршрутизация по результату оценки. Заявки с успешной оценкой — на обновление параметров залога; «Sale or Lead с неуспешной оценкой» — на переопределение ответственного.Назначение и приём оценки. «Лид» → выдача прав; «Сделка» → формирование ответственных и выдача прав. Оба пути ведут к ключевому шагу — «Принять результаты экспресс-оценки залога».Развилка приёма. «Отменить» завершает процесс; «Принять» → определение возможности принять оценку → «Можно принять» → обновление параметров залога → оповещение → завершение; «Невозможно принять» → возврат к приёму результатов.Проблемы: Единственная задача этапа — принять результаты экспресс-оценки, но при «невозможно принять» заявка просто возвращается на тот же шаг по кругу без лимита попыток и без эскалации — заявка может застрять именно здесь на неопределённый срок.
