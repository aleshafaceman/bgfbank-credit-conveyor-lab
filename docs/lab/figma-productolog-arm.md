## 1. Функции макета, которых нет в текущем лабораторном АРМ `/productolog/`

Сверка с описанным текущим столом (3 колонки deal-ops **Продукты / Риск / Матрица**; срезы со статусом/периодом/опциями; Excel-мок; `get_score`; границы шкал **0 / ∞**). В этом репозитории пути `/productolog/` нет.

2. Черновик **Заполняется** при закрытии незаполненного создания продукта/опции.
3. Карточка продукта с группами показателей («нужно будет выделить связки») и тумблер **Продукт без опций**.
4. Расширенные измерения среза в форме: **Справка о доходах**, **Трудовой статус**, **Регионы**, объект (**Квартира**), **Размер города**.

8. Набор шкал **Вариант 2**: **CLU** (36 мес.), **Семейное положение**, аккордеон **Количество созаемщиков / Максимальный срок доходов / Кредитный лимит**; ряд **Missings**; **+** ряд; сайдбар **Experian Score**.

## 2. Чего в макете делать нельзя по канону

1. **4-я цель кредита.** `CreditPurposeEnum` только `mortgage` / `cash_on_pledge` / `refinancing`. Не мапить в enum: **Покупка** (фильтр матрицы), **Кредит под залог недвижимости 2**, **Рефинансирование для пенсионеров**, **Наем**, **Квартира**, **До50лет**.
2. **Loginom из UI.** В макете Loginom нет — так и оставить. Solver читает конфиг (`/riskmanager/{slug}`, `/rbp_ltv_matrix`, `/products`).
3. **Отдельный продукт «коридор» / «купи ставку» как цель.** Слоёв «коридор» нет. Близкие вещи — **опции**: **Залог по сниженной ставке**, **Скидка 25%**, **Быстрый выход на сделку**, **Просто 0**. «Зелёный коридор» и «купи ставку» — опции, не 4-я цель и не отдельный продукт.
4. **Ставки и КВ из ячеек макета** не переносить как боевые. **Надбавка к комиссии** допустима в лабе только с **Периодом** (срок акции).
5. **Не копировать ПДн** из админки сотрудников (ФИО, телефон, email, чип пользователя в шапке).
6. Не тащить сюда кадры **Предложения банков / Анкета / шаги заявки / Калькулятор сравнения** — это не АРМ продуктолога.
7. Не делать из АРМ вызов бюро/Experian: пункт **Experian Score** — редактор шкал, не онлайн-скоринг.
